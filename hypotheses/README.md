# Hypotheses

This folder contains assumptions that can be tested through marketing, content, research, or customer behaviour.

Examples include:

- assumptions about the target audience;
- assumptions about the brand positioning;
- ideas about what content will increase engagement;
- assumptions about which offers may increase visits or bookings;
- assumptions about the best communication style for Instagram and Telegram;
- assumptions about how changes to the website, menu, wine card, or schedule may affect customers.

Each hypothesis should describe:

1. The assumption being tested.
2. Why it may be true.
3. What evidence would support or disprove it.
4. What test or observation will be used.
5. The result and the conclusion after testing.
